IGNITION - modern Windows compatibility layer                        v1.1
=========================================================================

Runs the 1997 game on 64-bit Windows 10/11. The game executable is NOT
modified, and no game files are included here.


INSTALL
-------
1. Copy  ddraw.dll  and  ign_compat.ini  into your Ignition folder,
   next to Ign_win.exe.
2. Run Ign_win.exe as normal.

That is the whole install. Windows searches a program's own folder before
System32, and ddraw is not a protected system name, so ours loads instead.

To uninstall, delete the two files. The game reverts to stock.


NEW IN v1.1
-----------
Alt-Tab no longer kills the keyboard. The game takes the keyboard in
"foreground" mode, so Windows releases it when the window loses focus, and
the game only tries to take it back on one error condition that never
actually happens. After a single Alt-Tab, nothing you pressed reached the
game again. The shim now re-acquires the keyboard when the window regains
focus. Set INPUT_REACQUIRE=0 to disable.


OPTIONAL
--------
dplayx.dll  - only needed if the game refuses to start at all with a
              missing-DLL error. DirectPlay is an optional Windows feature;
              without it the game cannot load. This stub satisfies that and
              disables LAN play. If the game already starts, skip it.


IF FULLSCREEN IS STUCK SMALL
----------------------------
Windows may have a "640x480" compatibility shim set for the game, which
makes it believe your monitor is 640x480. Right-click Ign_win.exe ->
Properties -> Compatibility -> untick "Run in 640 x 480 screen resolution".


SETTINGS  (ign_compat.ini)
--------------------------
WINDOWED        0 = borderless fullscreen, 1 = window
WINDOW_SCALE    window size multiplier when WINDOWED=1
SCALING         aspect | integer | stretch
FILTER          sharp | point | linear
VSYNC           0 / 1
PIXEL_FORMAT    auto is correct; p8 | rgb565 | xrgb888 to override
CPU_FIX         1 = stop the game pinning a CPU core (recommended)
INPUT_REACQUIRE 1 = keyboard keeps working after Alt-Tab (recommended)
BLOCK_JOYSTICK  1 = required; the legacy joystick API crashes on Win10/11
BLOCK_MCI       1 = disables CD music (the game plays fine without it)
TRACE           1 = write ign_compat.log for troubleshooting (slow)


NOTES
-----
* The game has no CD copy protection and runs with no disc. The only thing
  a disc ever provided was music.
* The menus are hardcoded to 640x480 whatever resolution you pick in the
  game, so menu art is always upscaled. Gameplay uses your setting.
